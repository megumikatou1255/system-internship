# TÌM HIỂU VỀ QUÁ TRÌNH CÀI ĐẶT MORPHEUS
## Yêu cầu
- Cài đặt theo mô hình All-In-One với DB Server riêng
> Yêu cầu về cấu hình:
- OS:
    + Ubuntu: 20.04, 22.04, 24.04
    + RHEL: 8.x, 9.x, 10.x
- Cấu hình phần cứng:
    + CPU: 4vCPU (minimum), 8vCPU (recommend)
    + RAM: 16GB (minimum)
    + Disk: 100GB (minimum)
- Cấu hình phân vùng:
    + /opt/morpheus: Tối thiểu 10 GB – 20 GB (Chứa mã nguồn nhúng và binary của Morpheus).
    + /var/log: Tối thiểu 20 GB (Chứa application logs).
- Mạng và cổng kết nối (Network & Ports)
    + IP & DNS: Cần một địa chỉ IP tĩnh (Static IP) và bản ghi FQDN/DNS phân giải chính xác (Forward & Reverse DNS).
    + Cổng Inbound mở vào máy Morpheus AIO:
        * Port 443 (HTTPS): Giao diện Web UI, API và Agent callback (Bắt buộc).
        * Port 80 (HTTP): Tự động redirect sang 443 (hoặc dùng để xác thực chứng chỉ Let's Encrypt).
        * Port 22 (SSH): Quản trị máy chủ.
    + Cổng Outbound từ máy Morpheus:
        * Cần kết nối Internet (hoặc repo local) để cài đặt các package bổ sung.
        * Mở các port quản trị tới các hạ tầng mà Morpheus sẽ kết nối quản lý:
            * vCenter / ESXi: Port 443, 902.
            * OpenStack: Port 5000 (Keystone), 8774 (Nova), 9696 (Neutron), v.v.
            * VM Guest / Agent Communication: Port 443 (cho Morpheus Agent giao tiếp ngược lại với máy chủ).
- Các yêu cầu khác:
    + NTP / Đồng bộ thời gian: Máy chủ phải được cấu hình đồng bộ thời gian (chrony / ntpd), lệch thời gian không quá 1 giây để tránh lỗi token và kết nối Cloud API.
    + SELinux / Firewall:
        + Với RHEL/CentOS: Cần mở port bằng firewalld hoặc tạm tắt để test.
        + Cấu hình SELinux ở chế độ permissive hoặc đảm bảo rule context đúng.

## Tiến hành cài đặt
### Cài đặt trên Ubuntu
#### DB Server
- Đầu tiên ta sẽ cần cấu hình trong DB Server trước
- Đăng nhập vào DB Server và chạy:
```bash
CREATE DATABASE morpheus DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'morpheus'@'%' IDENTIFIED BY 'MatKhauDBCuaBan';
GRANT ALL PRIVILEGES ON morpheus.* TO 'morpheus'@'%';
FLUSH PRIVILEGES;
```
- Mở file cấu hình MySQL và kiểm tra thông số khuyến nghị của Morpheus:
```bash
bind-address = 0.0.0.0
max_connections = 1000
innodb_buffer_pool_size = 4G   # (Tùy dung lượng RAM của DB Server)
innodb_file_per_table = 1
```
- Nếu có sửa đổi gì thì chạy câu lệnh `sudo systemctl restart mysql`
#### Morpheus Appliance
- Kiểm tra MA có thông cổng 3306 sang DB Server không
```bash
nc -zv <IP-DB-Server> 3306
```
- Nếu hiển thị Connection to <IP_DB_SERVER> 3306 port [tcp/mysql] succeeded! là thông mạng.
- Mở firewall
```bash
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
# Nếu không dùng ufw thì kiểm tra trạng thái bằng: sudo ufw status
```
- Tiến hành cài đặt gói Morpheus .deb
```bash
sudo apt install -y /opt/morpheus/morpheus-appliance_8.0.5-1_amd64.deb
```
- Cấu hình trỏ sang DB Server
```bash
sudo nano /etc/morpheus/morpheus.rb
```
- Dán nội dung như sau vào:
```bash
# Địa chỉ URL truy cập Web Morpheus (dùng IP của card mạng kết nối tới Windows hoặc FQDN)
appliance_url 'https://192.168.100.102'   # <-- Thay bằng IP máy Ubuntu này
# TẮT MySQL nhúng nội bộ
mysql['enable'] = false
# Khai báo thông tin kết nối DB Server riêng
mysql['host'] = '<IP_DB_SERVER>'
mysql['port'] = 3306
mysql['morpheus_db'] = 'morpheus'
mysql['morpheus_db_user'] = 'morpheus'
mysql['morpheus_password'] = 'MatKhauDBCuaBan'
# Các dịch vụ All-in-One khác (RabbitMQ, Elasticsearch nội bộ) giữ bật mặc định
rabbitmq['enable'] = true
elasticsearch['enable'] = true
```
**Hoặc**
```bash
appliance_url 'https://10.171.131.22'
elasticsearch['es_hosts'] = {'10.171.131.22' => 9200}
elasticsearch['node_name'] = '10.171.131.22'
elasticsearch['host'] = '0.0.0.0'

rabbitmq['enable'] = true
rabbitmq['host'] = '0.0.0.0'
rabbitmq['nodename'] = 'rabbit@node01'

mysql['enable'] = false
mysql['host'] = {'10.171.131.192' => 3306}
mysql['morpheus_db'] = 'morpheus'
mysql['morpheus_db_user'] = 'morpheus'
mysql['morpheus_password'] = 'dweQYkeyBHaF0T9ieUixRJZ'
user['uid'] = 899
user['gid'] = 899
# at the time of this writing, local_user is not valid as an option so the full entry is needed
node.default['morpheus_solo']['local_user']['uid'] = 898
node.default['morpheus_solo']['local_user']['gid'] = 898
elasticsearch['uid'] = 896
elasticsearch['gid'] = 896
rabbitmq['uid'] = 895
rabbitmq['gid'] = 895
guacd['uid'] = 894
guacd['gid'] = 894
```
- Tiến hành chạy reconfigure để khởi tạo hệ thống
```bash
sudo morpheus-ctl reconfigure
```
- Quá trình reconfig sẽ mất tầm 5-10p, sau khi xong thì màn hình sẽ hiển thị `Morpheus Reconfigured!` là done
- Kiểm tra trạng thái các tiến trình như `morpheus-ui, rabbitmq, elasticsearch, guacamole` đều có trạng thái `running`
```bash
sudo morpheus-ctl status 
```
