# TÌM HIỂU CÁC CÂU LỆNH THƯỜNG DÙNG TRONG OPENSTACK
## Các lệnh OpenStack cơ bản
- Kiểm tra phiên bản OpenStack
```bash
openstack --version
```
- Kiểm tra các service đang chạy
```bash
openstack service list
```
- Kiểm tra các endpoint
```bash
openstack endpoint list
```
- Kiểm tra catalog
```bash
openstack catalog list
```
- Kiểm tra token hiện tại 
```bash
openstack token issue
```
- Kiểm tra user
```bash
openstack user list 
```
- Kiểm tra project
```bash
openstack project list
```
- Kiểm tra role
```bash
openstack role list 
```

## Service
### Glance
- Liệt kê image
```bash
openstack image list
```
- Hiển thị thông tin chi tiết của image
```bash
openstack image show <image_id/image_name>
```
- Tạo/upload image
```bash
openstack image create "image-name" --file path/to/image --disk-format qcow2 --container-format bare --public
```
- Xóa image
```bash
openstack image delete <image-id>
```
- Download image
```bash
openstack image save --file duong/dan/file/dich <image_id>
```
- Xem thông tin chi tiết image
```bash
openstack image show <image_id>
```
### Cinder
- Liệt kê volume
```bash
openstack volume list
```
- Tạo volume 
```bash
openstack volume create --size 10 <volume-name>
```
- Xem thông tin chi tiết volume
```bash
openstack volume show <volume-name/volume-id> 
```
- Xóa volume
```bash
openstack volume delete <volume-name>
```
- Tạo volume từ image
```bash
openstack volume create <volume-name> --size 10 --image <image-id> 
```
- Attach volume vào VM
```bash
openstack server add volume <server-id> <volume-id> 
```
Sau đó kiểm tra bằng lệnh 
```bash
openstack volume show <volume-id>
```
Kiểm tra dòng `status = in-use`
- Detach volume
```bash
openstack server remove volume <server-id> <volume-id>
```
- Kiểm tra Cinder service
```bash
openstack openstack service list
```

## Neutron
- Neutron quản lý:
    + Network
    + Subnet
    + Port
    + Router
    + Security Group
    + Floating IP
### Network
- Liệt kê network
```bash
openstack network list
```
- Xem network
```bash
openstack network show <network-name/network-id>
```
- Tạo network
```bash
openstack network create <network-name>
```
- Xóa network
```bash
openstack network delete <network name/id>
```
### Subnet
- Liệt kê subnet
```bash
openstack subnet list
```
- Tạo subnet
```bash
openstack subnet create <subnet-name> --network <network-name> --subnet-range 192.168.100.0/24 --dhcp (optional)
```
- Xem subnet
```bash
openstack subnet show <subnet-name/id>
```
### Port
- Liệt kê port
```bash
openstack port list
```
- Xem thông tin chi tiết port
```bash
openstack port show <port-name>
```
- Tạo port
```bash
openstack port create <port-name> --network <network-name>
```
- Xóa port
```bash
openstack port delete <port-name>
```
### Router
- Liệt kê router
```bash
openstack router list
```
- Tạo router
```bash
openstack router create <router-name>
```
- Xem router 
```bash
openstack router show <router-name>
```
- Xóa router
```bash
openstack router delete <router-name>
```
- Gắn subnet vào router
```bash
openstack router add subnet <router-name> <subnet-name> 
```
- Gắn router vào external network
```bash
openstack router set <router-name> --external-gateway public
```

### Floating IP
- Liệt kê Floating IP
```bash
openstack floating ip list
```
- Tạo Floating IP
```bash
openstack floating ip create public
```
- Gắn Floating IP vào máy ảo
```bash
openstack server add floating ip <server-id> 203.0.113.100
```
- Xóa Floating IP
```bash
openstack floating ip delete <floating-ip-id>
```

### Security Group
- Liệt kê security group
```bash
openstack security group list
```
- Xem rule
```bash
openstack security group rule list default
```
- Cho phép SSH
```bash
openstack security group rule create --protocol tcp --dst-port 22 default
```
- Cho phép ICMP
```bash
openstack security group rule create --protocol icmp default
```
- Cho phép HTTP
```bash
openstack security group rule create --protocol tcp --dst-port 80 default
```

## Nova - Compute
- Liệt kê VM
```bash
openstack server list
```
- Tạo VM
```bash
openstack server create --img <img-id/name> --flavor <flavor-id/name> --network <network-id/name> vm-name
```
- Xem VM
```bash
openstack server show vm-name
```
- Xóa VM
```bash
openstack server delete vm-name
```
- Start/Stop VM
```bash
openstack server start/stop vm-name
```
- Reboot VM
```bash
openstack server reboot vm-name
```
- Pause/Unpause
```bash
openstack server pause/unpause vm-name
```
- Suspend/Resume
```bash
openstack server suspend/resume vm-name
```
- Xem console VM
```bash
openstack console url show vm-name
```
## Flavor - cấu hình phần cứng VM
- Liệt kê flavor
```bash
openstack flavor list
```
- Xem flavor
```bash
openstack flavor show fv-name
```
- Tạo flavor
```bash
openstack flavor create fv-name --ram 2048 --disk 20 --vcpus 2
```
