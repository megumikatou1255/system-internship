# TÌM HIỂU CÁC CÂU LỆNH THƯỜNG DÙNG TRONG OPENSTACK
## Các lệnh OpenStack cơ bản
- Kiểm tra phiên bản OpenStack
```bash
openstack --version
```
- Kiểm tra các service đang chạy
```bash
openstack service list
```
- Kiểm tra các endpoint
```bash
openstack endpoint list
```
- Kiểm tra catalog
```bash
openstack catalog list
```
- Kiểm tra token hiện tại 
```bash
openstack token issue
```
- Kiểm tra user
```bash
openstack user list 
```
- Kiểm tra project
```bash
openstack project list
```
- Kiểm tra role
```bash
openstack role list 
```

## Service
### Glance
- Liệt kê image
```bash
openstack image list
```
- Hiển thị thông tin chi tiết của image
```bash
openstack image show <image_id/image_name>
```
- Tạo/upload image
```bash
openstack image create "image-name" --file path/to/image --disk-format qcow2 --container-format bare --public
```
- Xóa image
```bash
openstack image delete <image-id>
```
- Download image
```bash
openstack image save --file duong/dan/file/dich <image_id>
```
- Xem thông tin chi tiết image
```bash
openstack image show <image_id>
```
### Cinder
- Liệt kê volume
```bash
openstack volume list
```
- Tạo volume 
```bash
openstack volume create --size 10 <volume-name>
```
- Xem thông tin chi tiết volume
```bash
openstack volume show <volume-name/volume-id> 
```
- Xóa volume
```bash
openstack volume delete <volume-name>
```
- Tạo volume từ image
```bash
openstack volume create <volume-name> --size 10 --image <image-id> 
```
- Attach volume vào VM
```bash
openstack server add volume <server-id> <volume-id> 
```
Sau đó kiểm tra bằng lệnh 
```bash
openstack volume show <volume-id>
```
Kiểm tra dòng `status = in-use`
- Detach volume
```bash
openstack server remove volume <server-id> <volume-id>
```
