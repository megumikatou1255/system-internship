# TRIỂN KHAI MỘT WEBSITE ĐƠN GIẢN TRÊN K8S
## Mô tả
- Chạy trên máy ảo Ubuntu Server 24.04 dựng cụm K8s bằng Minikube
- Cấu hình:
    + 4vCPU
    + 4GB RAM
    + 20GB Disk
## Thực hành
- Tiến hành tạo namespace `test` để triển khai website
```bash
kubectl create ns test
```
- Giới hạn quota cho namespace `test`
- Tạo file `test-quota.yaml` với nội dung sau:
```bash
apiVersion: v1
kind: ResourceQuota
metadata:
  name: test-quota
  namespace: test
spec:
  hard:
    # --- Giới hạn tài nguyên tính toán (Compute Resources) ---
    # Tổng requests (tài nguyên cam kết tối thiểu) của tất cả Pod
    requests.cpu: "1"
    requests.memory: 1Gi
    # Tổng limits (ngưỡng trần tối đa cho phép chạm tới)
    limits.cpu: "2"
    limits.memory: 2Gi
    # --- Giới hạn số lượng đối tượng (Object Counts) ---
    pods: "5"
    services: "5"
    services.nodeports: "2"
    persistentvolumeclaims: "4"
    requests.storage: 10Gi
```
- Đảm bảo namespace `test` đã tồn tại:
```bash
kubectl create namespace test --dry-run=client -o yaml | kubectl apply -f -
```
- Áp dụng file ResourceQuota:
```bash
kubectl apply -f test-quota.yaml
```
- Kiểm tra hạn mức tài nguyên đã được cập nhật chưa
```bash
kubectl get resourcequota -n test
# Hoặc
kubectl describe ns test
```
